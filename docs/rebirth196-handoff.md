`build_maps.py` สร้าง layout จากฟังก์ชัน `layout(i)` ใหม่ทุกครั้ง ถ้าจะเปลี่ยนผังถาวรให้แก้ฟังก์ชันนี้ด้วย ส่วน `build_catalog.mjs` อ่าน JSON layout เพื่อผูกจุดเข้าเกม ใช้ตัวสร้างนี้ได้ซ้ำโดยไม่เพิ่มพอร์ทัล/NPC ซ้อน

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' -b --python scripts/rebirth196/build_maps.py -- --root .
node scripts/rebirth196/build_catalog.mjs
node build-vercel.mjs
```

Blender ใช้ XY เป็นพื้น Z ขึ้น ส่วนเกมใช้ `x=X, z=-Y` จุด spawn ต้นทาง `(0,60)` พอร์ทัลย้อนกลับ `(0,66)` พอร์ทัลไปบทต่อไป `(0,-66)` ยกเว้นบทสุดท้ายไม่มีพอร์ทัลไปต่อ ตัว binder ขยับจุด NPC/มอนเล็กน้อยไปยังช่องที่เดินถึงได้จริง

ถ้าเกลา `.blend` ด้วยมือ ต้อง export `.glb` และ bake nav ใหม่ให้ตรง geometry ด้วย ห้ามใช้ nav เก่าหลังเปลี่ยนสะพาน/พื้น/สิ่งกีดขวาง ตัว generator จะเขียนทับงานเกลาใน `.blend` จึงควรเก็บสำเนาหรือเปลี่ยน workflow เป็น export/bake จากไฟล์ที่เกลาแล้วก่อน

ไฟล์ `.blend` และสคริปต์ Python ไม่ถูกส่งเข้า `dist` ตาม build เดิม ลิงก์ดาวน์โหลด Blender ใน lab ใช้กับ local source server ด้านบน

แปลง PNG เป็น WebP คุณภาพ 88 โดยคงขนาดเดิม ไม่วาดหรือดัดเนื้อภาพด้วยสคริปต์ ต้นฉบับ PNG อยู่ที่ `outputs/rebirth196/story-masters/` (ไม่ได้ stage เข้า Git) ภาพรวมตรวจงานอยู่ที่ `outputs/rebirth196/story-contact.png` ชุด prompt ต้นทางอยู่ใน `assets/rebirth196/story-prompts.json` และบันทึกที่มาอยู่ใน `generated-images.json`

## ส่วนที่ตั้งใจให้ Claude เกลาต่อ

- แมพเป็น blockout สีพื้น มีธีมและผังใช้งานแล้ว ยังต้องเกลาสถาปัตยกรรม รายละเอียด แสง วัสดุ ความสูงและองค์ประกอบภาพให้เข้ากับแมพจริงของเกม
- NPC ในเกมและมอนสเตอร์ทั้ง 30 ชนิดยังใช้ sprite ตัวแทนเดิมอย่างชัดเจน (`artProxy` / `proxyId`) ภาพคัตซีนเป็นงานใหม่ทั้งหมด ต้องสร้าง sprite/animation ของตัวใหม่เพิ่มภายหลัง
- ยังไม่เพิ่มการ์ดใหม่ 30 ใบและเอฟเฟกต์การ์ด เพราะยังไม่มีสเปกบาลานซ์หรือภาพการ์ด แยกมอนต้นแบบด้วย `draft:true` การ์ดและดรอปเดิมยังตรวจครบตามเดิม
- ค่า HP/โจมตี/EXP/รางวัลและจำนวนมอนเป็นค่าร่าง ต้องทดสอบเวลาเก็บเลเวล 1–99 ของคนจุติก่อนปล่อยจริง ค่าเบี้ยจากมอนเป็นศูนย์ รายได้ใหม่มาจากเควสกับการขายเศษขวัญ
- กลไกในเควสเป็น talk/enter/level/defeat ที่เล่นจบได้แล้ว ยังไม่มีฉากคุ้มกันแบบจับเวลา การพายเรือ interactive หรือระบบ escort เฉพาะเควส
- ประตูตรวจจุติและเลเวลแล้ว แต่ยังไม่ได้บังคับเปิดเฉพาะพลบค่ำหรือบังคับจบเนื้อเรื่องเดิมก่อนเข้า ต้องตกลงกติกาก่อนเพิ่มเงื่อนไขเหล่านี้
- **ยังไม่ได้ทำ PvP จุติ 4+** ในแมพ 4–5 ข้อความในแผนต้นฉบับเป็นแนวคิดให้พิจารณาต่อ ขอบเขตที่ผู้ใช้ยืนยันรอบนี้คือแมพร่าง + ภาพ + เควส
- Atlas ภูมิประเทศเดิมยังใช้ภาพโลกเก่า เดินข้ามแมพใหม่ผ่านพอร์ทัล/เควสได้แล้ว ถ้าจะวาร์ปตรงจาก atlas ให้เพิ่ม UI ของห้าภพแยกต่างหาก
- ยังไม่พุชขึ้น production เพราะผู้ใช้ระบุว่าจะให้ Claude เกลาแมพต่อ
