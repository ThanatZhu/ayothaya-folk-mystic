## สิ่งที่ต้องรักษา

- Google UID + server ID เป็นขอบเขตข้อมูลเสมอ; guest ไม่ทับ cloud และ server 1 ไม่ทับ server 2
- ห้ามนำ chapter-01 ไปเปลี่ยนแมพจริงโดยตรงจนมี runtime quest service และ migration ที่ทดสอบแล้ว
- ค่า 31 นาที, จำนวนช่องกระเป๋า และค่า EXP เป็นค่าเริ่มต้นสำหรับทดสอบ ปรับจากการเล่นจริงได้
- ทุกเฟสจบด้วยรายการสิ่งที่ใช้งานได้ ผลทดสอบ และข้อจำกัด ไม่เรียกว่าพร้อมเปิด MMO จนเซิร์ฟเวอร์ควบคุมผลเกมจริง
- ไม่มีการเปิดระบบซื้อขายระหว่างผู้เล่นก่อน authority ของไอเทม/เงินอยู่บนเซิร์ฟเวอร์

## ตรวจข้อมูล Phase 1

รัน `npm run check:content` ตรวจชื่อและ ID อ้างอิงกับแมพจริง กราฟเควสต์ จำนวนของ/เงิน/EXP และเงื่อนไขปลดล็อก รายการข้อมูลบทแรกยังไม่ถูกโหลดในเกม และ build เว็บไซต์ไม่จำเป็นต้องรวมไฟล์ออกแบบเหล่านี้

## Phase 2 / A01 pilot (0.16)

- ห้องลอง `sprite-lab.html` เปิดได้โดยไม่ล็อกอิน: ชาย/หญิง, แปดทิศ, หมุนกล้อง, จุดวางเท้า, หายใจเบา ๆ และ reduced motion
- ภาพใหม่สามแผ่นใน `assets/directional/`; source PNG เก็บต้นฉบับไม่แก้ทับ ภาพ 5x2 ใช้เฉพาะสามคอลัมน์แรก ส่วนด้านหลังเลือกจากแผ่นแก้ใหม่
- manifest ระบุ crop และจุดเท้ารายภาพ; runtime จัดลงช่อง 192x192 ที่ฐาน (96,180) โดยใช้ nearest filtering
- ตัวเลือกในเมนูเกมสำหรับหมอผีเท่านั้น: เปิดชุดมาตรฐาน 8 ทิศเพื่อทดสอบกับการเดิน/กล้องจริง ปิดได้ทันที โหลดล้มเหลวกลับภาพเดิม ไม่เปลี่ยน appearance ในเซฟ
- ไม่ใช้การกลับภาพด้านขวาเป็นด้านซ้าย; แต่สัดส่วน ท่ามือ ตำแหน่งคทาและเครื่องประดับจากภาพสร้างยังต้องเก็บความต่อเนื่องระหว่างทิศ โดยเฉพาะรอยต่อ S/SE และด้านหลัง
- A02/A03 ยังไม่เสร็จ: ภาพใหม่ทั้งหมดเป็น neutral turnaround; การขยับในเกมยังใช้ mesh deformation เดิม ไม่ใช่เฟรมเดิน 8 เฟรม/ทิศหรือ animation ที่มี contact frame จริง
- A04 ยังไม่เสร็จ: ชุดหลายทิศยังไม่แยกชั้นเสื้อผ้า/ผม/อาวุธ การแต่งตัวเดิมใช้กับภาพรุ่นเดิมต่อไป

### ตรวจรับ pilot 0.16

- Node tests 72 ข้อผ่าน, static build และ content validator ผ่าน
- Browser local: ชาย/หญิง, เลือกด้านหลัง, หมุนกล้องเปลี่ยนมุมถูกต้อง; mobile 844x390 ไม่มี document overflow
- ในเกม: เปิดต้นแบบ, เดิน W เห็นภาพหลัง, ปิดกลับผม/ชุดที่แต่งไว้เดิม; ไม่พบ console errors ในขั้นตอนที่ตรวจ
- ยังไม่ใช่ผลทดสอบ FPS บนมือถือจริง และยังไม่ใช่ animation clips หลายทิศครบ Phase 2
