# ข้อกำหนด Asset สำหรับ Phase 2

สถานะ: เป้าหมายผลิต ไม่ใช่รายการภาพที่สร้างเสร็จแล้ว

## ตัวละครต้นแบบ

เริ่มหมอผีชายและหญิงอย่างละหนึ่งตัว ใช้แบบ Folk Mystic เดิม ตรวจในเกมทั้งคอมและมือถือก่อนขยายไปครบ 14 รูปลักษณ์ ทุกอาชีพต้องมีคุณภาพเท่าตัวต้นแบบ ไม่ใช้จำนวนเฟรมเป็นเกณฑ์เดียว

- สัดส่วนประมาณ 2.5–3 หัว ตาและมืออ่านง่าย ฉากและตัวละครใช้ความหนาเส้นกับขนาดพิกเซลที่เข้ากัน
- เฟรมใช้งานเริ่มที่ 192×192 px พื้นหลังโปร่งใส; จุดยืนกลางฐาน (96,180) เหมือนกันทุกเฟรม เผื่อพื้นที่อาวุธและท่าโจมตี เปลี่ยนขนาดได้หลังดูตัวต้นแบบจริง
- ทิศใช้งาน 8 ทิศ; ผลิต 5 ทิศ N, NE, E, SE, S และสะท้อนอีก 3 ทิศเฉพาะชิ้นส่วนที่สมมาตร อาวุธ เสื้อ และยันต์ที่ไม่สมมาตรต้องมีข้อยกเว้นหรือวาดฝั่งนั้นเพิ่ม
- เดินไปหลังต้องเห็นด้านหลังจริง กลับทิศโดยเลือก atlas ตามมุมกล้องเทียบเวกเตอร์เดิน
- Pixel sampling แบบ nearest หลีกเลี่ยงการขยายย่อที่ทำให้ความหนาพิกเซลสั่น และไม่ขยายตัวทั้งภาพเพื่อแทนการงอเข่า

| ท่า | เฟรมต่อทิศเริ่มต้น | จุดตรวจ |
|---|---:|---|
| ยืน | 4 | เท้าอยู่กับพื้น หายใจที่อก/ไหล่ |
| เดิน | 8 | contact → down → passing → up ครบสองข้าง แขนสวนขา |
| โจมตี | 8 | ง้าง ออกแรง จุดกระทบ คืนท่า; ตรงกับจังหวะ damage event |
| ร่าย | 8 | เตรียมมือ สะสมแสง ปล่อย กลับยืน |
| ถูกโจมตี | 3 | สะดุ้งระยะสั้น กลับท่าต่อได้ |
| หมดแรง | 5 | ลงน้ำหนักก่อนล้มและจุดยืนไม่กระโดด |

ชุดฐาน 36 เฟรม × 5 ทิศ = 180 ช่องต่อรูปลักษณ์ หรือ 360 ช่องสำหรับหมอผีชาย/หญิงก่อนข้อยกเว้นการสะท้อน ทั้ง 14 รูปลักษณ์อย่างน้อย 2,520 ช่อง ท่าพิเศษตั้งรับ ก้าวหลบ คำนับ ดีใจ และพักเป็นชุดต่อเติม ไม่รวมในยอดนี้

## การแยกชิ้นส่วน

body / hair / outfit / eyes / facialHair / tattoo / weapon ต้องใช้เฟรม ทิศ และ anchor ชุดเดียวกัน มี masks บอกส่วนที่ต้องอยู่หน้า–หลังลำตัวและอาวุธ หากเปลี่ยนผมแล้วผมติดอยู่กลางหน้าขณะหันหลัง ถือว่ายังไม่ผ่าน

metadata ต่อคลิป: direction, frameDurationMs, loop, footContacts, anchors, hitEventFrame, frameBounds และ facingMirrorPolicy แยกคีย์ภาพจาก class ID และ appearance ID เพื่อให้ใช้ animation controller ร่วมกันได้ พระ/แม่ชีใช้ข้อกำหนดศีรษะประจำอาชีพที่มีอยู่

## รายการ Asset บทแรก

- NPC หลัก 6 คน: idle, talk, ภาพหน้าสนทนา และไอคอนบทบาท
- มอนเดิม 4 ชนิด: idle, move, attack, hit, defeat; บอสใหม่ 1 ตัวพร้อมเอฟเฟกต์คำเตือนสองรูปแบบ
- ดันเจียน: ประตูเข้า ทางเดินกว้าง ลานไหดิน แท่นประทีปสภาพดับ/ติด ซากรากไม้ และทางออก
- ไอคอน: อาวุธฝึก 7 แบบ ยา อาหาร เสื้อ วัตถุดิบ 3 ชนิด ของเควสต์ 3 ชนิด และเงิน
- UI: เครื่องหมายเควสต์ รับได้/กำลังทำ/ส่งได้ กระเป๋า ร้านค้า หน้าของรางวัล และอาชีพขั้น 2
- เสียง: ก้าวพื้นดิน/ไม้/หิน โจมตีตามอาวุธ ร่าย ถูกตี รับของ เควสต์สำเร็จ เมือง ทุ่ง และศาลา; ปรับระดับเสียงและปิดได้

## Pipeline และการตรวจรับ

วาด/สร้างภาพต้นแบบ → จัด sprite layers และเวลาเฟรมในโปรแกรมที่ export PNG ได้ → ส่งออก PNG + metadata → ตรวจกรอบ/anchor/alpha → เปิดหน้าทดลองทุกทิศ → ใช้ในเกม → ทดสอบมือถือจริง

ใช้ Blender ต่อสำหรับฉาก 3D และ UV เครื่องมือวาดไม่บังคับ Aseprite เก็บต้นฉบับแก้ไขได้พร้อมแหล่งที่มา/สิทธิ์ใช้งานทุกชิ้น ภาพที่สร้างด้วย AI ต้องผ่านการตรวจความต่อเนื่องของหน้า เสื้อ มือ และอาวุธ ไม่ถือว่าพร้อมใช้เพียงเพราะมีช่องครบ

ผ่านเมื่อขนาดหน้าและเท้าไม่กระโดดระหว่างเฟรม ไม่มีอาวุธงอผิดรูป ไม่มีภาพตัดขอบ ชุดแต่งตัวเข้ากับทุกทิศ และหยุดเดินแล้วไม่ไหลต่อโดยไม่มีการก้าว วัดประสิทธิภาพก่อนเพิ่ม atlas ทุกอาชีพพร้อมกัน
