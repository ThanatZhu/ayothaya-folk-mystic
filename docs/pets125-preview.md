# Pet gacha preview and retired capture quest

Historical preview milestone. The subsequent user-approved live integration is documented in pets126-live.md; the isolated lab remains separate from live balances.

User-approved scope: preview only, no real-money top-up. Ten newly generated transparent creatures, S ×3 / A ×3 / B ×4, including five flying and five ground pets. Each has a stat bonus and a different special skill. `premium-pets.js` is the shared draft catalog; `pet-skill-preview.js` demonstrates numerical damage, healing, mana, shields, mitigation, roots, slows, armor breaks and cleanse effects in an isolated training sandbox. The following demo moves the starting artwork; it is not a finished multi-frame gait or wing animation.

The draft currency is Khwan Gems (แก้วขวัญ), separate from cowries. The lab starts with 10,000 test gems, permits test grants and reset, charges 100 per pull, and supports 1 or 10 pulls. Draft base rates: S 3%, A 17%, B 80%; within each tier pets are equally likely. A run of 79 non-S pulls guarantees S on pull 80. Any S resets this counter. Stars remain 1 when duplicates arrive; the player spends 1/2/3/4 same-pet duplicate copies through an explicit upgrade button for stars 2/3/4/5. Draft stat scaling is +25% of the original bonus per star, and skill potency +15% per star with one second less cooldown per star. All values are reviewable, not approved paid-store balance or prices.

The lab only writes `ayothaya-pets125-preview:v1` in localStorage. It cannot call payment, profile, wallet or real collection APIs; its pure helper functions do not grant production currency. A preview link lives in the existing pet window. Legacy pets and capture items remain usable outside the story. Launching a paid system later requires a server-owned wallet/inventory, durable atomic rolls and idempotent fulfillment after a verified payment; nothing in the browser demo constitutes such a paid entitlement.

The mandatory capture quest t13 and its pet-food reward are removed. t12 no longer gives lures or directs players to catch pets; Grandma Sai instead sends players to prepare supplies at Mae Bua's market. Story version 3 migrates old v2 indexes: before t13 unchanged, t13 moves to t14 without a reward, later indexes shift down one, completed stories remain completed. Existing steps/kill counts and all other quest IDs survive. The new active story has 22 quests.

All ten original PNGs are retained in outputs/pets125/originals, with game-ready 512px alpha WebP copies in assets/pets125. prompts.json records the built-in image_gen prompts; art-checks.json under outputs records alpha and size verification. Runtime artwork totals about 0.6 MB.

Validation: all 458 Node tests passed. `scripts/check-pets125.mjs` exercises a real local host and browser: v2 capture-quest migration preserves XP, coins and the legacy pet; the game pet window opens the preview link; single-tier deterministic draws, duplicate consumption through five stars, all ten skills and image decoding work; demo storage leaves the game account keys unchanged. Screenshots at 1440×900, 844×390 and 390×844 have no horizontal page overflow. Run after `node build-vercel.mjs`, passing the absolute Playwright module path as the script's first argument. Local QA outputs stay in outputs/pets125 and are not deployed.
