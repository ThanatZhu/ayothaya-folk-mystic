# ทิศทางเอฟเฟกต์สกิล — facing200

แก้บน origin/main ที่ 6489ef6 ใน worktree แยก ไม่ปนกับแมพร่างหรือไฟล์ที่แก้ค้างใน checkout อื่น

## สาเหตุและการแก้
ภาพสกิลหลักใน role-sheet-vfx.js เป็น Sprite ซึ่งไม่มีการปรับภาพตามทิศโจมตี แม้ตำแหน่งเอฟเฟกต์และท่าตัวละครจะอ้างอิงเป้าหมายถูกแล้ว ภาพทวน/ศรที่วาดหัวไปทางขวาจึงชี้ย้อนเมื่อผู้เล่นโจมตีทางซ้าย

- ส่งกล้องจริงผ่าน createLiveRoleVfx → createSheetVfx แล้วฉายทิศจากจุดร่ายไปยังเป้าหมายลงพิกัดหน้าจอ จึงรองรับการหมุนกล้อง
- ตรวจภาพครบ 101 sheets (98 active ของ 7 อาชีพ รวมสาย Master และ novice 3 ภาพ) และกำหนด policy ใน skill-effect-facing200.js แยกภาพมีทิศ, ภาพที่กลับเฉพาะซ้ายขวา และภาพที่ต้องตั้งตรง
- กลับ UV ภายในช่อง atlas แต่ละเฟรม ไม่ใช้ scale ติดลบของ Sprite เพราะ Three.js คิดขนาด Sprite เป็นค่าบวก และไม่แก้ texture ร่วมที่อีกคนกำลังใช้
- UV ปกติและ UV กลับด้านใช้ Source ภาพเดียวกันและถูก dispose ตามอายุ cache เหมือนเดิม ไม่เพิ่มไฟล์ภาพหรือโหลดภาพซ้ำ
- หัวลูกศร/ทวนชี้ตามทิศเป้า แต่บัฟ ศาลา โล่ เสาแสง และสกิลตกจากฟ้าไม่หมุนกลับหัว
- ศรพระรามและซุ่มยิงเก็บยันต์/พงไม้ช่วงเตรียมไว้ตั้งตรง แล้วค่อยปรับทิศเมื่อปล่อยศร
- ทิศเก็บจาก cast เดิม มี fallback แยกผู้ร่ายแต่ละคนสำหรับการร่ายที่จุดต้นทางเท่ากับปลายทาง การเปลี่ยนเป้าหรือผู้ร่ายคนอื่นไม่พลิกภาพของ cast ที่ค้างอยู่
- slot ที่นำกลับมาใช้รีเซ็ตทั้ง UV และ rotation จึงไม่ติดทิศจากเอฟเฟกต์ก่อนหน้า
