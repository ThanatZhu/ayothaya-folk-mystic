# Space and direct NPC interaction — 137

Pressing Space within 2.3 world units of an NPC opens that NPC's existing conversation or mentor window. The same key event never sends an attack. Holding Space across closing a dialogue remains consumed until release; chat, editable fields and native HUD button activation retain their behavior. Away from NPCs, Space retains the existing attack action. The contextual prompt explains Space/click on desktop and touch on phones.

Stationary NPCs, mentors and walking citizens expose their existing live sprite to picking. Clicking or touching the actual painted silhouette opens its normal conversation. A distant selection uses the existing route walker and opens after reaching talk range. Transparent atlas padding is excluded using the current pose's texture UVs and alpha, including mirrored frames. A candidate is recorded at pointer-down so movement during a short press does not switch the intended NPC. Drags and pinches keep their existing movement/camera behavior. Ground-target skill placement continues to use ground picking.

This is a client interaction change. Existing server-side NPC range, quest and shop validation and all combat messages are unchanged.

Verification: `tests/npc137.test.mjs` checks nearest NPC selection, dead/distant players and opaque/mirrored texture picking. `scripts/check-npc137.mjs <absolute Playwright module>` uses an isolated real socket host and rendered desktop/touch clients to check Space, holding/releasing, focused attack buttons, chat spaces, body clicks, walking to talk, normal attack away from NPCs and native touch. Wandering passers-by are omitted from this input fixture to make the target reproducible; the live maps retain their citizens.

The full regression suite passed 505/505. The rendered touch check also confirms the NPC prompt stays above collapsed chat and clear of the left quick slots.
