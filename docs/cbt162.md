# CBT activity preview

User decision: start 1 November 2026, Thai time; no end date yet. Preview first. Nothing in this change starts a contest, settles ranks, creates entitlements, grants items or modifies the existing duel tournament.

The generated icon is appended to the existing `hud-chips` container, so the current desktop right rail and mobile right-to-left event row own its placement. The illustrated activity popup opens after loading and blocking panels are clear, once per character/server/tab session. It can always be reopened via the CBT icon. Other HUD positions remain unchanged.

Preview: `cbt-event-lab.html`. Runtime: `cbt-event-ui.js`, `cbt-event.css`, policy/copy: `cbt-event.js`. Original and optimized generated assets live in `assets/events-cbt162/`; prompt/source metadata is alongside them. Typography remains Mali, using the game's existing generated frame and buttons.

Revised rewards, using the real gold-bar wallet and inventory: final rebirth 10 for everyone who qualifies; power and arena tiers 1, 2, 3, 4–9; seven distinct login days, chapter-one completion and verified bug reports as optional activities. Lower tiers and optional activities give gold bars only. Top tiers and rebirth completion add existing break-guard and lek-lai items. No speculative cosmetics, custom titles, auras or new pets are promised. All reward attachments have been tested against the existing mailbox claim path; no grants are triggered by the preview. All quantities are proposals. Claim time and mail delivery after opening are still proposals pending owner confirmation.

- Proposed arena controls: no same-account matches, at most one scored match per opponent/day and ten scored matches/day; at least ten valid matches against five accounts to qualify. Persist pair/day counters across reconnects and server restarts, bind a match source to a server-created match ID, and settle once. Review suspicious intentional losses; do not blindly block shared Wi-Fi households.
- Assess rebirth-10 time to completion using actual CBT telemetry before committing a duration.
- Implement account-bound entitlements and idempotent mailbox settlement after approving the prize list; never trust browser storage or preview progress for eligibility. Retain entitlements through any CBT character reset.
- Never auto-enable claims merely because 1 November passes: `status: preview`, null end, claims disabled and ranked queue disabled are explicit.

The owner approved publishing all pending work on 25 October 2026. This publishes the CBT preview only; claims, matchmaking scores, settlement and real-money payments remain disabled.
