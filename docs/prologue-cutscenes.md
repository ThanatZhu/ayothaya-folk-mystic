# บทนำ "ทุ่งนิมิต": ภาพคัทซีนเต็มจอ (prompt สำหรับ ChatGPT)

ภาพทั้ง 5 ภาพเป็นคัทซีนเต็มจอของบทนำผู้เล่นใหม่ ลำดับเรื่องเป็นดังนี้:

1. ฝันเห็นทุ่งนิมิต
2. พบวิญญาณครูและเลือกอาชีพเพื่อลองพลัง
3. บอสตื่นที่ลานศิลา
4. พลังที่ยืมมาสลายไป
5. ตื่นที่อยุธยาในสภาพผู้ฝึกตน

## วิธีใช้

1. ทุกภาพต้องเจนใน **บทสนทนาเดียวกัน** ของ ChatGPT ให้ส่ง "STYLE BLOCK" ด้านล่างก่อนหนึ่งครั้ง แล้วค่อยส่ง prompt ทีละภาพ ภาพจะได้ออกมาเป็นชุดเดียวกัน
2. ถ้ามีภาพหน้า login (`assets/arrival186/river-gate.png`) หรือภาพเรื่องเดิม (`assets/story160/*.webp`) ให้แนบไปด้วยเป็นภาพอ้างอิง **สไตล์** เท่านั้น
3. ขนาดภาพเป็นแนวนอน 16:9 (1920×1080 หรือ 1536×864) บันทึกเป็น PNG แล้วส่งไฟล์มาตามชื่อในแต่ละหัวข้อ ผมจะแปลงเป็น webp และวางลง `assets/prologue/` เอง
4. **ห้ามมีตัวละครผู้เล่นในภาพ** เพราะผู้เล่นเลือกได้ 7 อาชีพ 2 เพศ เกมจะวางสไปรต์ตัวละครจริงของผู้เล่นทับลงไปเอง ทุกภาพจึงเว้นที่ยืนว่างไว้ให้
5. **ห้ามมีตัวหนังสือ กรอบ หรือ UI ในภาพ** คำบรรยายภาษาไทยเกมใส่เองด้วยฟอนต์ Mali ในกรอบที่มีอยู่แล้วของเกม
6. ภาพถูกครอปด้านบนและล่างบนมือถือจอยาว ของสำคัญจึงต้องอยู่ในช่วง 70% กลางภาพ และ 1/4 ล่างของภาพต้องโล่งและมืดกว่าส่วนอื่น เพราะเป็นที่วางกล่องคำบรรยาย

## STYLE BLOCK (ส่งก่อนภาพแรก)

```
You are illustrating full-screen story cutscenes for "Ayothaya Folk Mystic", a warm Thai folk-fantasy RPG set in an
enchanted Ayutthaya / Himmapan world. Keep ONE consistent look across every image I ask for in this chat:
premium hand-painted game storybook art with subtle crisp pixel-textured brushwork, rich layered foliage, authentic
Thai details (teak, laterite, red-and-gold banners, sweeping Thai roof lines, banyan trees, spirit houses), deep
atmospheric depth, soft cinematic light. Palette: jade and moss greens, muted warm ochre, cream, temple gold, and
cyan spirit light for anything magical. Dreamlike but tender and inviting, never horror.
Format for every image: one wide landscape 16:9 image (1920x1080), opaque, a single coherent scene (no collage, no
panels). Keep the story subject inside the central 70 percent; extend the environment naturally to all edges so it can
be cropped. Keep the bottom quarter calmer and slightly darker (a subtitle box will sit there).
Never draw the player hero (the game composites the real character sprite), never draw text, letters, captions, UI,
frames, borders, logos or watermarks.
```
