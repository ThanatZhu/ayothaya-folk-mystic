# Persistent field HUD (0.34)

Owner selected the MMORPG concept HUD but requested the existing radial skill wheel and the concept sword attack button. This supersedes UI-33's full-screen journal.

- Direct profile, skills, players and chat buttons. Map remains directly clickable. Compact jade/gold profile and minimap, left-side party, lower-left chat, separate Base/Job EXP along the bottom edge.
- mmo-hud.js and mmo-hud.css are unchanged: all ten radial slots, radii, cooldowns and layout are preserved. New SVG sword artwork changes only attack presentation; hold-to-attack, Space, and AUTO keep existing handlers.
- hud-panels.js opens native nonmodal dialogs and closes other utility panels. Skills, roster, map and normal account profile do not block movement or combat. Account save/auth failures still use the existing blocking safety path. Escape closes utility panels. Space on a focused panel button activates that button, rather than also attacking.
- Skill window uses existing profession-specific skill atlases. No world art, character data/schema, Firebase rules, or multiplayer protocol changes.

Validation: 96 tests pass; static build succeeds. Local browser at 1280x720, 844x390 and 667x375: no page overflow. At 1280x720 utility panel ends at y445, at the wheel's top; at 667x375 none of its buttons overlap the panel. With Skills open, W changed coordinates from X0/Y0 to X-1/Y2 and casting slot 5 used 18 MP and entered cooldown. No native modal and no inert elements. Switching profile/map closes the previous panel; Escape closes the map. No browser console errors. Real phone hardware and mobile keyboard not tested.

Owner follow-up: removed the camera/how-to panel and its HUD/profile launchers. Legacy hidden control IDs stay for camera bindings; ordinary Q/E and gesture controls are retained.
