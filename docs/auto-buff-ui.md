# บัฟและการตั้งค่า AUTO

- ภาพวาดใหม่ 36 ไอคอน: บัฟ 24 / ดีบัฟ 12 ใช้ต้นฉบับ image_gen ไม่แก้พิกเซล บรีฟจริงอยู่ใน assets/status/art-prompts.txt
- buff-gallery.html แสดงภาพใหญ่และตัวอย่าง 24 / 36 px ส่วน auto-buff-lab.html เปิดพรีวิว HUD โดยไม่ล็อกอินหรือเปลี่ยนข้อมูลผู้เล่นจริง
- หน้าอัปสกิลเหลือเฉพาะเรียน/อัปเลเวล/เงื่อนไขสกิลหลักและ Master
- ฟันเฟืองบนขอบขวาบนปุ่ม AUTO เปิดหน้าตั้งค่า 3 แท็บ: เปิดปิดสกิลอัตโนมัติ / จัดตำแหน่งปุ่มลัด / น้ำยา HP และ MP
- แตะต้นทางแล้วแตะปลายทางหรือเมาส์ลากเพื่อสลับช่อง ย้ายแล้วสกิลคงสถานะ AUTO ของตนเองและเรียงลำดับใช้งานตามปุ่มลัด บันทึกผ่าน API เดิมของเกม แยกตามอาชีพและอุปกรณ์เดิม
- ฟันเฟืองเป็นปุ่มข้างเคียง ไม่ซ้อน button ไว้ใน button กดแล้วไม่สลับเปิดปิด AUTO พื้นที่กด 44 px ปุ่ม AUTO 76 px บนคอม และ 51–64 px ตามขนาดจอเล็ก
- แถบสถานะใต้โปรไฟล์ใช้ภาพกับเวลาเหลือจริง รวมเกราะ สถานะผิดปกติ และบัฟอาหาร อาหารออนไลน์ส่งชนิดและเวลาจากเซิร์ฟเวอร์ใน snapshot ส่วนตัวเท่านั้น ไม่มีการเพิ่มบัฟปลอม
- ภาพสำหรับบัฟสกิลร่างใหม่พร้อมแล้ว แต่กลไกของ 112 สกิลร่างยังเป็น sandbox ตามขอบเขตเดิม จึงไม่แสดงบัฟเหล่านั้นในเกมจนกว่าจะเชื่อมกลไก
- tests/auto-settings-status.test.mjs ตรวจการสลับช่อง AUTO และบัฟรวมถึงการส่งอาหารเฉพาะเจ้าของ; scripts/check-auto-buff-ui.mjs ตรวจ 7 อาชีพ 8 viewport การบันทึกหลังโหลดใหม่ การแยกหน้าอัปสกิล และขอบเขตปุ่ม
- การทดสอบมือถือใช้ viewport จำลอง ไม่ใช่การทดสอบฮาร์ดแวร์ iPhone / Android จริง ยังไม่ push หรือ deploy
