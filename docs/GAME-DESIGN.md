# อโยธยา · แบบเกม Phase 1

สถานะ: แบบพร้อมใช้พัฒนาบทแรก — 12 ตุลาคม 2026

เอกสารนี้และข้อมูลบทแรกยังไม่ใช่เควสต์ที่เปิดเล่นแล้วในเว็บ

## 1. ประสบการณ์ที่ต้องการ

เกม Chibi Pixel 2.5D โลกแฟนตาซีไทย มีอยุธยาเป็นเมืองหลวงและศูนย์กลางการเดินทาง กล้องหมุนได้ ผู้เล่นควรรู้สึกว่าได้กลับบ้านเมื่อเข้าเมือง และพบเรื่องลึกลับเมื่อออกนอกกำแพง ใช้ชีวิตในเมือง พบคนคุ้นหน้า แล้วเติบโตจากการช่วยเหลือและผจญภัย

- คงบรรยากาศ Folk Mystic: เรือนไทยไม้ หลังคาดินเผา ร่มไทร ประทีป คลอง เรือ และวิญญาณสีเขียวอมฟ้า
- อ่านท่าศัตรูและพื้นทางเดินได้ แม้จอมือถือเล็ก ไม่มีสิ่งตกแต่งบังคำเตือนการโจมตี
- เมืองทั้งหกปลอดภัย ไม่มีมอนเกิดหรือไล่ตามเข้ามา แมพต่อสู้แยกจากเมือง
- คอม: WASD, Space, F, 1–9/0; มือถือแนวนอน: จอยซ้าย ปุ่มต่อสู้ขวา
- ใช้เทคโนโลยีเดิม: Three.js, JavaScript modules, PNG atlases, Blender, Firebase และ Vercel ก่อนเพิ่มเครื่องมือใหม่

## 2. เรื่องหลัก: สายใยขวัญ

ความทรงจำ คำสัญญา และความผูกพันระหว่างผู้คนทิ้งสายใยไว้กับสถานที่ คืนหนึ่งประทีปทั่วอยุธยาดับพร้อมกัน สัตว์ออกจากป่า ภูตหลงทาง และชื่อบนศาลาถูกลบ ผู้เล่นเป็นนักเดินทางผู้มองเห็นด้ายขวัญที่ผู้อื่นมองไม่เห็น

บทแรกพบว่า ผู้เฝ้าศาลาไม่ได้ชั่วร้าย แต่สูญเสียความทรงจำว่าตนคอยใครอยู่ การต่อสู้เปิดโอกาสให้คืนประทีปและความทรงจำ เมื่อแสงกลับมา ด้ายเส้นหนึ่งชี้ออกไปยังหัวเมืองอื่น

โลกนี้เป็นเรื่องแต่งที่ได้รับแรงบันดาลใจจากวัฒนธรรมไทย ไม่ระบุรัชกาล ปี หรืออ้างว่าเป็นเหตุการณ์ประวัติศาสตร์จริง ชื่อเมืองที่ใช้อยู่คงเดิม

## 3. บทบาทของเมือง

| เมือง / แมพนอกเมือง | บุคลิกและปมเรื่อง | บริการและอาชีพเด่นที่วางไว้ |
|---|---|---|
| อยุธยา / ทุ่งนอกกำแพง | ศูนย์กลางการค้า จุดเริ่มเหตุประทีปดับ | ตลาด คลัง จุดรวมปาร์ตี้ สำนักฝึก นักดาบ |
| บางไทร / ป่าไทรและบึงหมอก | รากไทรเก็บคำสัญญาที่ถูกลืม | สมุนไพร เรือ หมอผี |
| ละโว้ / ซากเมืองศิลา | บันทึกกับศิลาจารึกเล่าเรื่องไม่ตรงกัน | สำรวจโบราณสถาน เครื่องราง จอมโจร |
| สุพรรณ / ป่าไผ่นอกค่าย | ความกลัวของคนฝึกกลายเป็นเงาในอาวุธ | โรงตีเหล็ก ลานฝึก นักมวย นักทวน |
| พิษณุโลก / ป่าริมแคว | สัตว์หนีเสียงระฆังที่ไม่มีผู้ตี | ติดตามรอยสัตว์ สมุนไพร นายพราน |
| นครศรีธรรมราช / ชายฝั่งเครื่องเทศ | เครื่องรางจากเรือพาความทรงจำข้ามทะเล | เครื่องราง การเดินเรือ พระและแม่ชี |

บทแรกใช้เพียงอยุธยา ทุ่งนอกกำแพง และดันเจียนใหม่ “ศาลาประทีปร้าง” เมืองอื่นที่มีอยู่ยังเดินทางได้ตามเดิม แต่คอนเทนต์บทใหม่ของเมืองเหล่านั้นอยู่ Phase 8

## 4. เส้นทางบทแรก

เวลาในตารางเป็นเป้าหมายสำหรับปรับสมดุล ยังไม่ใช่เวลาที่วัดจากผู้เล่นจริง รวมกิจกรรมประมาณ 31 นาที ตั้งเป้าประสบการณ์แรก 30–45 นาทีเมื่อรวมเดินทางและอ่านบทสนทนา ใช้รถเกวียนเดิมและจุดเควสต์ใกล้เส้นทางหลักเพื่อลดการเดินผ่านพื้นที่ว่าง

| ลำดับ | เควสต์ | สิ่งที่ผู้เล่นทำ | นาที | EXP เควสต์ |
|---|---|---|---:|---:|
| 1 | คืนที่ประทีปดับ | คุยลุงเรืองและขุนอินทร์ เรียนรู้ปุ่มคุย | 2 | 20 |
| 2 | เตรียมตัวออกประตูเหนือ | รับอาวุธฝึกตามอาชีพและสวมใส่ | 2 | 30 |
| 3 | ทางเกวียนที่เงียบลง | ปราบหมูป่า 3 ตัว ทดลองเลือกเป้าและ AUTO | 4 | 45 |
| 4 | กลิ่นสมุนไพรในหมอก | ปราบภูตมอส 3 ตัว เก็บใบจันทร์ 3 ใบ | 3 | 55 |
| 5 | เตรียมพร้อมอีกครั้ง | ต้มยา ซื้อเสื้อผ้าฝ้ายและสวมใส่ | 3 | 50 |
| 6 | รอยเล็กข้างคันนา | ปราบคางคก 4 ตัว สำรวจเกวียนพัง | 4 | 80 |
| 7 | ชื่อที่เหลือบนฐานประทีป | อ่านรอยจารึกและเปิดทางเข้าศาลา | 2 | 80 |
| 8 | เสียงในไหดิน | ปราบไหผี 4 ตัว เก็บเศษประทีป 3 ชิ้น | 4 | 70 |
| 9 | ผู้เฝ้าประทีปดับ | หลบการโจมตีบอส แล้วคืนแสงที่แท่น | 5 | 50 |
| 10 | ด้ายเส้นแรกของผู้เดินทาง | กลับรายงาน รับ EXP ถึงเกณฑ์และเปิดทางอาชีพขั้น 2 | 2 | 50 |

EXP เควสต์ 530 + การต่อสู้ที่จำเป็น 370 = 900 ถึง Lv.10 โดยไม่บังคับวนฟาร์มเพิ่ม การล่าระหว่างทางทำให้ถึงก่อนกำหนดได้ เควสต์ 10 ไม่ต้องใช้ Lv.10 เพื่อรับรางวัล จึงไม่เกิดเงื่อนไขวนกัน

อาวุธฝึกให้ตอนรับเควสต์ 2 เพียงครั้งเดียว ไม่รอให้สวมอาวุธก่อนจึงแจก รางวัลเควสต์รับได้ครั้งเดียวด้วย claim ID ช่วงเควสต์ 7–9 รับ/อัปเดตผ่านสมุดภารกิจได้ ไม่ต้องย้อนกลับเมืองทุกห้อง

## 5. NPC บทแรกและของที่ต้องสร้าง

คงชื่อ NPC เดิมทั้ง 30 คน และผูก stable ID ไว้ในข้อมูลบทแรก ไม่ใช้ลำดับใน array เป็นตัวอ้างอิงเซฟ

| NPC หลัก | หน้าที่ในบทแรก |
|---|---|
| ลุงเรือง | ต้อนรับ สอนเดินทาง และส่งต่อปมเรื่อง |
| ขุนอินทร์ | งานนอกกำแพง รายงานผล และเชื่อมเนื้อเรื่อง |
| แม่บัว | ร้านยา อาหาร และสูตรสมุนไพร |
| ครูแสนดาบ | อาวุธฝึกและโต๊ะสำนักสำหรับเลือกสายขั้น 2; ครูเฉพาะสายที่หัวเมืองเปิดภายหลัง |
| เจ้าจุก | ชี้เบาะแสเกวียนและศาลา |
| ช่างเทียน — NPC ใหม่ | เสื้อผ้าฝ้าย เบาะแสรอยซ่อมประทีป และงานช่าง |

ต้องมีภาพเฉพาะและไอคอนบทบาทของ NPC หลัก 6 คนก่อน ข้อมูลของอีก 25 คนเป็นขอบเขตงานต่อ ไม่ถือว่าร้านหรือบริการเหล่านั้นทำงานแล้ว

มอน 4 ชนิดใช้ชื่อและ type เดิมได้ แต่ปรับข้อมูลรางวัลแยกตามพื้นที่ บอสใหม่ 1 ตัว: ผู้เฝ้าประทีปดับ มีคำเตือนพื้นชัดเจนและช่องปลอดภัย ทุกอาชีพหลบด้วยการเดินปกติได้ AUTO ไม่หลบแทนผู้เล่น

## 6. ตัวละคร ไอเทม และความก้าวหน้า

คง 7 อาชีพเริ่มต้นและ 14 สายขั้น 2 จาก advancement.js รวมตัวเลือกพระ/แม่ชีตามรูปลักษณ์ ใช้ชุดความสามารถจริงที่ต่างกัน: รับความเสียหาย คุมระยะ ยิงไกล หมัดต่อเนื่อง เคลื่อนตัว อาคม และสนับสนุน

- EXP สะสมตามตารางข้อมูลใหม่; จำนวนมอนที่ปราบเป็นสถิติแยก ไม่ใช่ตัวกำหนดเลเวลอีกต่อไปหลัง migration
- บทแรกอาชีพขั้น 2 ต้อง Lv.10 และจบ ch01-return; ผู้ที่ปลดล็อกในเซฟเดิมแล้วต้องรักษาสายเดิม
- อุปกรณ์เริ่มต้น: อาวุธ ชุด และเครื่องราง; รูปลักษณ์ตกแต่งแยกจากค่าสถานะอุปกรณ์
- กระเป๋าวางแผนเริ่ม 32 ช่อง ของวางซ้อนสูงสุด 99; ไอเทมเควสต์แยกช่อง ไม่ขายหรือแลกได้
- เงินใช้ชื่อ “เบี้ย” บทแรกได้จากเควสต์ 320 ซื้อเสื้อที่จำเป็น 25; ยาราคา 6 มีช่องทางเก็บสมุนไพรฟรีหากเงินหมด
- ของจำเป็นต่อเควสต์ได้แน่นอนตามเงื่อนไข ไม่บังคับสุ่มดรอป การฟาร์มซ้ำจะไม่ให้รางวัลเควสต์ซ้ำ
- ตายแล้วกลับจุดปลอดภัย ไม่ลบเควสต์หรือของถาวร บอสเริ่มการเผชิญหน้าใหม่และไม่แจกของซ้ำจากการโหลด

## 7. ข้อตกลงข้อมูลและออนไลน์

Phase 1 ไม่เปลี่ยน schema เซฟจริง กำหนด schema 2 สำหรับพัฒนาภายหลัง โดยคง UID, server ID, character identity และ revision เดิม เพิ่ม progression, inventory, equipment, wallet, quests และ claimedRewards

ทุกการซื้อ คราฟต์ รับรางวัล หรือเปลี่ยนอุปกรณ์ต้องสำเร็จทั้งชุดใน transaction เดียว เช่น รับรางวัล = ตรวจเควสต์ + เพิ่มของ/เงิน/EXP + บันทึก claim ID ไม่มีสภาพที่หักของแล้วเซฟเงินล้มเหลว คำสั่งมี requestId สำหรับ retry ซ้ำโดยไม่ให้ของซ้ำ

ก่อนเริ่ม Phase 3 ให้แยก domain functions รับข้อมูลและคืนผลลัพธ์ ไม่ผูกกับ DOM เช่น awardExperience, applyDamage, acceptQuest, claimQuest, buyItem และ equipItem UI ส่งคำขอผ่าน service adapter; Phase 7 ย้าย authority ของการต่อสู้และรางวัลไปเซิร์ฟเวอร์จริง

Firebase Auth คงเป็นระบบยืนยันตัวตน Firestore ใช้บันทึกถาวร ไม่ใช้เขียนตำแหน่งทุกเฟรม ระบบ multiplayer วางเป็นเซิร์ฟเวอร์ห้องผ่าน WebSocket แยกจาก static hosting; เลือกผู้ให้บริการเมื่อมีผล load test ไม่ซื้อบริการใน Phase 1

การย้ายเซฟ: สำรอง schema 1 → ตรวจรูปแบบ → แปลงแบบ idempotent → ตรวจผล → เขียน revision ใหม่ ห้ามล้างตัวละครเพื่อรองรับ schema ใหม่ หากเปลี่ยนตารางเลเวลให้รักษาเลเวลเดิมและความคืบหน้าภายในเลเวล พร้อมเก็บ legacyKills; ต้องมีตารางครบถึงระดับสูงสุดเดิมก่อนเปิด migration จริง

## 8. เกณฑ์จบบทแรกก่อนขยายโลก

1. ผู้เล่นใหม่ทั้ง 7 อาชีพจบเส้นทางได้โดยไม่ใช้คำสั่งทดสอบหรือเงินแจกนอกระบบ
2. ไม่มีเควสต์ติดเพราะเงินหมด กระเป๋าเต็ม ออกจากเกม ตาย หรือเดินทางผิดเมือง
3. เปิดเกมอีกเครื่องด้วยบัญชีเดิมแล้วได้เควสต์ ของ เงิน อุปกรณ์ และรูปลักษณ์ตรงกับเซฟล่าสุด
4. เมืองไม่มีมอน และดันเจียนไม่ทำให้ปุ่มกลับ/บัญชีบนมือถือกดไม่ได้
5. ทดสอบบน Android และ iPhone จริงก่อนอ้างความลื่นบนมือถือ ตั้งเป้า 30 FPS อย่างสม่ำเสมอในฉากปกติและปรับคุณภาพได้
6. คำสั่งรับรางวัล/ซื้อของซ้ำไม่เพิ่มของหรือหักเงินซ้ำ; แท็บเก่าทับเซฟใหม่ไม่ได้
