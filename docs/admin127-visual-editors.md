# Visual admin editors

The existing luxury back office now opens skills and monsters in a picture-and-details view, with a numeric-table switch for legacy skill balance and monster editing. Both editable views share the same draft, original values, field bounds, undo buttons and save API. The working header stays visible while scrolling; the large hero is compacted, and the JSON export is under More Tools. The existing Mali font and jade/gold colors remain.

The default skill page shows the actual role skill definitions used by the current game, including 14 Master branches across seven advanced classes. This is explicitly a read-only reference. The legacy balance editor remains available under a clearly labeled selector and keeps its existing save behavior. It does not claim to modify the newer role skill schema. The novice's in-game legacy skill set is also shown. Icons reuse the measured in-game skill atlases.

All 53 current monster types have their actual game portrait, plus the drop headers and nine map-boss rows. The existing 24 creatures use runtime atlas extraction. The 29 chapter-two creatures use 160px alpha WebP thumbnails mechanically extracted from the game's masked idle frames. The new thumbnails total 344,750 bytes, so opening the monster page does not download 29 full animation sheets. `scripts/build-admin-monster-portraits.mjs` reproduces them; assets/admin127/monsters/manifest.json records the sources. Search, normal/elite/boss filters, card fields, numeric table fields and reset remain linked.

The selected player's gift area separates pet/gem grants from bag/item grants. Pet selection uses all ten pictures, owned star/copy counts and one selected state. Quick gem amounts, a clear-selection button and a recipient/amount/pet summary precede the grant button. Invalid or empty grants are disabled. Drafts are kept per recipient across refreshes and tab switches; duplicate clicks do not send twice. Existing server authorization, durable saves and grant receipts are unchanged.

The latest map/monster release from main was merged while preserving its map-boss controls, spawn rules, animation files and translations. Validation after merging: 473 Node tests passed. scripts/check-admin127.mjs checks every portrait, all eight class options and 14 Master branches, nine map bosses, editable card/table synchronization and undo, pet-gift drafts and one-time duplicate grants. It also captures 1440×900, 844×390 and 390×844 layouts with no horizontal page overflow. Its sign-in fixture is isolated to the local test browser; production authentication is unchanged.
