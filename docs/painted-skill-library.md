## ระบบภาพและการทดสอบ

โหลดภาพเฉพาะสกิลที่เลือก แคชสูงสุด 6 ชีต (โหมดเบา 4) และมีงบวัตถุภาพสูงสุด 64 ชั้น ใช้ภาพตัวละครเต็มตัวที่เกมมีอยู่ จัดท่าและการเคลื่อนที่ใหม่ ไม่มีการตัดแขนขามาขยับ พาสซีฟสาธิตเฉพาะเมื่อเงื่อนไขเริ่มทำงาน ไม่กำหนดให้มีออร่าใหญ่เล่นวนในเกม

ทดสอบเปิดและ seek ทุก 112 รายการในเบราว์เซอร์ มีหลักฐานภาพและ checks.json ใน outputs/all-skill-library/ และมี unit tests ใน tests/all-skill-library.test.mjs การตรวจจอเป็นเบราว์เซอร์จำลอง ยังไม่ใช่ทดสอบเครื่อง iPhone/Android จริง
