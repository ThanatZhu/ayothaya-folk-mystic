# CBT artwork sources

Created with built-in image_gen. These are decorative preview assets; they do not activate an event or grant rewards.

- `icon-source.png` → `icon.webp`: a compact Thai fantasy lotus event crest in antique gold and jade, with a readable silhouette at HUD size and a transparent background.
- `poster-source.png` → `poster.webp`: a landscape Thai MMORPG activity illustration with three connected sections: magical rebirth in lotus light, a champion on a podium, and a one-on-one sword duel. Live HTML adds Thai titles and dates rather than baking them into the art.
- `close-source.png` → `close.webp`: a new square jade close button with ornamental antique-gold framing and a large clear gold X, with a transparent outer background.

The descriptions above summarize the source briefs; they are not a verbatim prompt transcript. The daily bounty batch has its separate exact prompt set in `../bounty163/prompts.json`.
