# 📝 แพตช์โน้ต 0.98

**🌐 หน้าเว็บใหม่ของเกม**
• https://ayothaya-folk-mystic.vercel.app/ เปิดมาเจอหน้าแนะนำเกม: ระบบเด่น อาชีพ แผนที่ กิจกรรมประจำสัปดาห์ (นับถอยหลังกิลด์วอร์และทัวร์นาเมนต์) และสถานะเซิร์ฟเวอร์จริง
• กด "เล่นเลย" เพื่อเข้าหน้าเลือกตัวละคร (ย้ายไปอยู่ที่ /play.html · บุ๊กมาร์กเดิมจะเปิดหน้าแนะนำก่อน กดเล่นเลยต่อได้เลย)

**📜 เควสเนื้อเรื่องใหม่ · ทำเควสไปด้วย ได้เรียนวิธีเล่นไปด้วย**
• 23 เควส ใน 3 บท ทุกเควสสอนหนึ่งระบบ และรางวัลคือของที่ใช้ในเควสถัดไป
• เริ่มเกมได้ **อาวุธเริ่มต้นตามอาชีพ** → สอนสวมใส่ → สอนตีมอนกับดื่มยา → อัปสกิล → เปิด AUTO
• Lv.6 สอน **ตีบวก** ที่ครูแสนดาบ · ต่อด้วยการ์ดใบแรกและสอน **ใส่การ์ด**
• Lv.10 ขึ้นไป สอนคราฟต์ จับสัตว์เลี้ยง ซื้อขาย บอสโรงสี ดันเจี้ยน เปลี่ยนอาชีพ (ได้อาวุธอาชีพใหม่) บึงบัว กิลด์ และท้าดวล
• กล่องเควสมีบรรทัด "วิธีทำ" ใต้ทุกขั้น กด ▶ เดินไป แล้วตัวละครจะเดินไปเอง
• ⚠️ ทุกตัวละครเริ่มสายเควสใหม่ที่เควส 1 ขั้นที่ทำได้อยู่แล้ว (เช่น ใส่อาวุธอยู่ เลเวลถึงแล้ว) จะผ่านเองทันทีพร้อมรับรางวัล

**🎓 บททดสอบเปลี่ยนอาชีพ ยากขึ้น 3 ด่าน**
• ล่ามอนสเตอร์ 40 ตัว (Master 100 ตัว)
• ล้มบอสบททดสอบ: หุ่นฟางพันเชือก (Master: พญาวานรบึง)
• นำวัตถุดิบกับเบี้ยไปส่งครู (อาชีพแรก 2,000 เบี้ย · Master 10,000 เบี้ย)
• พอ Job ตันจะมีหน้าต่างเควสเด้งบอก พร้อมปุ่มเดินไปลานครู
