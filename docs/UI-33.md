# Travel journal menu (0.33)

The top-right Menu button opens a native modal dialog with five categories: Character, World, Companions, Emotes, and Settings. Submenu actions reuse profile/account, skills, city map, overview, online roster/chat, four emotes, camera settings, fullscreen, and the existing save-before-return flow. There are no placeholder inventory, shop, quest, or guild controls.

Implementation: game-menu.js and game-menu.css; CSS loads after mmo-hud.css. Existing menu-skills/menu-players/menu-chat IDs retain notification dots, aggregated onto the category and menu launcher. Player names use textContent. Gameplay input and camera shortcuts are blocked during dialogs, Escape closes the journal, and native focus trapping/restoration is retained. Chat explicitly expands the collapsed mobile dock before focusing the input.

Visual language: teak header and sidebar, jade cards, antique gold active state, custom lightweight SVG line icons, Mali typography, restrained entrance/hover motion and reduced-motion support.

Validation: npm test (96 passing; socket tests require access to loopback), npm run build, npm run check:content. Browser: 1280x720 and 844x390; no page or journal pane overflow at these sizes; buttons at least 44 px high. Opened profile, skill window, city map, online roster, settings, chat input; tested Escape focus return, blocked M shortcut, emote menu dismissal and return-to-lobby retaining the local test character. Online UI exercised against the loopback test server, not a real Google account. Real-device keyboard/fullscreen behavior remains unverified.
