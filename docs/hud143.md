# User-arranged mobile HUD

Mobile toolbar controls reuse the generated emote/run images from ui-action141
and AUTO art from ui-combat142. World uses the existing painted map icon/frame.
The default movement pad is inset at least 56px from the left and 32px from the
bottom, with safe-area offsets retained.

Open AUTO → gear → skill positions → **ลากจัดปุ่มบนหน้าจอ**. The editor overlays
drag handles on the live controls, rather than casting or swapping their skills.
Move the four skill slots, attack, page swap, AUTO, movement pad or target button
with touch/mouse. Save keeps positions in this device/browser's local storage;
Cancel restores the last saved layout. Reset affects only the current
orientation and requires Save. Portrait and landscape have separate profiles.

**คัดลอกตำแหน่ง** copies JSON containing normalized control centers and viewport
dimensions, also exposing selectable text if clipboard access fails. The user
can paste it in chat to request a new shared default. No account/character data
is included or sent to the server. Other viewport sizes clamp each control into
reach; user-chosen arrangements may overlap until adjusted in the editor.

The editor captures gestures and keyboard focus while open. Existing hotbar
order, skill levels, cooldowns and AUTO settings remain owned by their original
modules. Four screen-slot locations apply consistently across skill banks.

Validation: model tests cover finite/known control IDs, independent orientation
profiles, normalized scaling and edge clamps. `scripts/check-hud143.mjs` uses
native touch drag to verify movement without casting, save/reload, orientation
switching, JSON export, cancel/reset, the live AUTO menu and skill checklist,
ten mobile/tablet sizes, keyboard viewport and desktop behavior.

Regression run: 512/513 passed in the combined suite. The unchanged
frontier-network38 transient monster-hit snapshot wait timed out, then passed
when rerun with the new model/i18n tests (5/5). Browser checks reported no page
errors and verified that dragging sends no attack/skill commands.
