## งานค้างที่พบเพิ่ม

- AUTO บอส: เทสต์ hunter/shaman ใน tests/boss-auto201.test.mjs ล้มเดิม 2 ข้อ ต้องแยกตรวจทางเดินจริงกับข้อสมมติในเทสต์ก่อนแก้ ไม่ปรับสมดุลเพื่อทำให้เทสต์ผ่าน
- เสียง: หน้าเกมทดสอบพบไฟล์ทั่วไป audio180 หาย 19 URL เป็นปัญหาเดิม งาน BGM lofi ทุกเพลงยังหยุดตามคำขอก่อนหน้า และอยู่คนละ worktree ไม่รวมในรอบนี้
- FPS เครื่องจริงยังต้องวัด profiler และอุปกรณ์จริง การทดสอบ software WebGL ไม่ยืนยัน FPS ผู้เล่น

## ลำดับแนะนำ

1. ตรวจ AUTO บอสและความเสถียร/FPS
2. QoL ฟาร์ม: คลิกขวาใส่อาวุธ → โจมตีแล้วเข้าระยะ → เควสวิ่งเอง → ขายหลายชิ้น/ทั้งหมด → tooltip
3. ถอดการ์ดและ live DPS แล้ววัดวงจรคราฟต์/บอส
4. จับเวลาเล่นจริงและจูนเป้าหมาย 4–7 วัน/หนึ่งเดือนจากข้อมูล
5. ก่อน CBT: กรองชื่อ แจ้งอัปเดต โหลดเทสต์ และตรวจปั๊มอันดับ
6. ทดสอบ/ปรับ PvP-GvG หลายผู้เล่น
7. พรีเมียมและประมูลหลังเศรษฐกิจนิ่ง

ยังไม่ได้พุชหรือ deploy รอบนี้ ไม่มีการแตะบัญชีจริง แจกของ รีเซ็ตบัญชี เปลี่ยนราคา หรือเปิดชำระเงินจริง
